## Proje hakkında
VerimLab, endüstri mühendisliği öğrencilerinin temel konuları pratik örneklerle çalışabilmesi için hazırlanmış Türkçe, tarayıcı tabanlı bir hesaplama aracıdır.

## Araçlar
| Modül | Ne yapar? |
|---|---|
| Ekonomik Sipariş Miktarı (EOQ) | Sipariş ve stokta tutma maliyetlerini dengeleyen miktarı hesaplar. |
| Başabaş Analizi | Sabit maliyet, satış fiyatı ve değişken maliyet ile başabaş miktarını bulur. |
| Verimlilik Analizi | Çıktı / girdi oranını ve önceki dönemle değişimi hesaplar. |
| Zaman Etüdü | Gözlem sürelerinden ortalama, normal süre ve standart süreyi hesaplar. |

## Özellikler
- Responsive arayüz ve Türkçe açıklamalar
- Formüller, girdi doğrulama ve anlaşılır hata mesajları
- Sonuçları tarayıcıdaki yerel hesaplama geçmişine kaydetme
- Harici JavaScript kütüphanesi veya kurulum gerektirmeyen yapı

## Nasıl çalıştırılır?
1. Depoyu bilgisayarına indir veya klonla.
2. index.html dosyasını tarayıcıda aç.
3. Bir modül seç, değerleri gir ve hesapla.

    git clone https://github.com/PirateEmre/verimlab.git
    cd verimlab

## Teknolojiler
- HTML — sayfa yapısı
- CSS — responsive tasarım
- Vanilla JavaScript — hesaplama mantığı ve etkileşimler
- LocalStorage — hesaplama geçmişi

## Öğrenme notu
Bu proje öğrenme ve pratik amaçlıdır. Gerçek operasyonel kararlarda kullanmadan önce model varsayımlarını, veri kalitesini ve birimleri kontrol et.
